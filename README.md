<h3>Queueo</h3>

<p>
  <strong>
    Engineering Ticketing Platform with OCR Processing and 
    Decision-Tree Priority Routing
  </strong>
</p>

<p>
  Queueo is a web and mobile ticketing platform designed to manage
  internal engineering and technical-support requests. It provides
  centralized ticket tracking, department-head approval, OCR-assisted
  document processing, rule-based priority analysis, and a complete
  audit trail.
</p>

<a href="https://github.com/JustineClaro/Queueo_system">
  <img src="https://img.shields.io/badge/View_Repository-4169E1?style=for-the-badge&logo=github&logoColor=white" alt="View Queueo repository">
</a>

</div>

<br>

<h3>Key Features</h3>

- Web, mobile, and installable PWA access
- Internal engineering and technical-support ticket submission
- Department-head review and approval workflow
- OCR processing for images, PDFs, and DOCX files
- Rule-based priority analysis with typo-tolerant keyword detection
- Priority-based and first-in-first-out queue ordering
- Ticket assignment, transfer, status tracking, and resolution acceptance
- In-app notifications, email alerts, internal messaging, and announcements
- Administrative dashboards, reports, audit logs, and user management
